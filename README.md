# SHARE-ED Documentation

## ภาพรวมโครงการ

Repository นี้จัดทำขึ้นเพื่อรวบรวมและจัดเก็บเอกสารประกอบการพัฒนาระบบ **SHARE-ED** โดยครอบคลุมกระบวนการวิเคราะห์ความต้องการ การออกแบบระบบ การกำหนดความต้องการของผู้ใช้งาน ตลอดจนการวางแผนและทดสอบระบบ

เอกสารทั้งหมดได้รับการรวบรวมและปรับปรุงสำหรับการส่งมอบโครงการในเวอร์ชันสุดท้าย **v2.0.0 (Final Release)**

## เอกสารประกอบโครงการ

| ลำดับ | เอกสาร | รายละเอียด |
|---|---|---|
| 1 | [เอกสารข้อกำหนดความต้องการระบบ (SRS)](SPRS-Project-Document-SHARE-ED-lasted.docx) | เอกสารวิเคราะห์และกำหนดความต้องการของระบบ |
| 2 | [User Stories และ BDD](SPRS-E2E-BDD-UserStories-SHARE-ED-lasted.docx) | เอกสารความต้องการและพฤติกรรมของระบบจากมุมมองผู้ใช้งาน |
| 3 | [แผนการทดสอบและรายงานผล](SPRS-Test-Plan-and-Report_SHARE-ED-lasted.docx) | เอกสารแผนการทดสอบและรายงานผลการทดสอบระบบ |
| 4 | [กรณีทดสอบระบบ (Test Cases)](SPRS-Test-Cases-SHARE-ED-lasted.docx) | เอกสารชุดกรณีทดสอบและผลลัพธ์ที่คาดหวัง |

## ประวัติการอัปเดต

### v2.0.0 — Final Release

การปรับปรุงเอกสารสำหรับการส่งมอบโครงการฉบับสมบูรณ์ ประกอบด้วย

- ปรับปรุงเอกสารข้อกำหนดความต้องการของระบบ (SRS)
- ปรับปรุงเอกสาร User Stories และ Behavior-Driven Development (BDD)
- อัปเดตแผนการทดสอบและรายงานผลการทดสอบระบบ
- ปรับปรุงเอกสารกรณีทดสอบระบบ (Test Cases)
- นำเอกสารเวอร์ชันเก่าที่ไม่ใช้งานออกจาก Repository
- รวบรวมเอกสารฉบับล่าสุดสำหรับการส่งมอบโครงการ

## การจัดการเวอร์ชัน

โครงการใช้ GitHub ในการจัดเก็บเอกสารและติดตามประวัติการเปลี่ยนแปลง โดยใช้ Git Commit สำหรับบันทึกการแก้ไข และ Git Tag / Release สำหรับระบุเวอร์ชันของเอกสาร

**v2.0.0** เป็นเวอร์ชันสุดท้ายที่จัดเตรียมสำหรับการส่งมอบโครงการ

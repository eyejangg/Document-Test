# SHARE-ED Documentation

## ภาพรวมโครงการ

Repository นี้จัดทำขึ้นเพื่อรวบรวมและจัดเก็บเอกสารประกอบการพัฒนาระบบ **SHARE-ED** โดยครอบคลุมกระบวนการวิเคราะห์ความต้องการของระบบ การออกแบบระบบ การกำหนดความต้องการของผู้ใช้งาน การวางแผนและดำเนินการทดสอบระบบ รวมถึงการทดสอบ API

เอกสารทั้งหมดได้รับการรวบรวมและปรับปรุงเป็น **เวอร์ชัน 2.0.0 (Final Release)** เพื่อใช้ประกอบการส่งมอบโครงการและการประเมินผลทางการศึกษา

- รวบรวมเอกสารสำหรับการส่งมอบโครงการฉบับสมบูรณ์

## การจัดการเวอร์ชัน

โครงการใช้ GitHub ในการจัดเก็บและติดตามประวัติการเปลี่ยนแปลงของเอกสาร โดยมีแนวทางดังนี้

- **Git Commit:** บันทึกประวัติการแก้ไขและปรับปรุงเอกสาร
- **Git Tag:** กำหนดหมายเลขเวอร์ชันของเอกสาร
- **GitHub Release:** เผยแพร่ชุดเอกสารแต่ละเวอร์ชันสำหรับการส่งมอบ

เวอร์ชัน **v2.0.0** เป็นชุดเอกสารฉบับสุดท้ายที่จัดเตรียมสำหรับการส่งมอบโครงการ SHARE-ED
